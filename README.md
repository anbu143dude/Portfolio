# Anand Babu P — Professional Portfolio

https://anbu143dude.github.io/Portfolio/

Static HTML/CSS/JavaScript portfolio, hosted by GitHub Pages from main.

## Features
- Inter body typography and Manrope headings, served by Google Fonts (open-source SIL Open Font License fonts).
- AOS 2.3.4 scroll reveals, served by jsDelivr. AOS is MIT licensed: https://github.com/michalsnik/aos
- Reduced-motion support and a motion toggle; content remains readable when scripts or CDN resources fail.
- Interactive delivery workflow with accessible buttons and live descriptions.
- Semantic headings, Person structured data, profile image and downloadable CV.

All work history is in static HTML. SEO metadata is not an ATS score or a guarantee of recruitment outcomes.

Open index.html to preview. No build step is required. Updates to main redeploy via GitHub Pages.
